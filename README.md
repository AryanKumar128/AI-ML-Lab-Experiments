### Artificial Intelligence and Machine Learning — Prolog Practical Repository

## ⚙️ Installation and Setup

### Step 1 — Install SWI-Prolog

Download and install SWI-Prolog from its official website:

https://www.swi-prolog.org/

### Step 2 — Open the Prolog Interpreter

Launch SWI-Prolog and load your experiment file.

Example:

```prolog
?- [experiment01].
```

### Step 3 — Execute Queries

Run queries using the predicates defined in your program.

Example:

```prolog
?- student(aryan).
```

The query above is an example only. Use predicates that actually exist in your experiment file.

### Step 4 — Verify the Output

Test the program with suitable queries and record the observed output for your laboratory submission.
